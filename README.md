## Thesis project — WiFi Anomaly Detection System

> Real-time network anomaly detection for embedded environments

```
ESP32 ──MQTT──▶ FastAPI ──▶ Isolation Forest ──▶ PostgreSQL
   (sensor)     (broker)     (ML model)            (storage)
                                │
                                ▼
                          Docker Compose
                       (one command deploy)
```

**What it does:** ESP32 scans WiFi networks and publishes signal data via MQTT. A FastAPI backend receives the stream, runs it through a trained Isolation Forest model, and stores detected anomalies in PostgreSQL. Entire stack containerized with Docker.

**Stack:** `Python` `FastAPI` `scikit-learn` `PostgreSQL` `Docker` `MQTT` `ESP32` `Pydantic` `SQLAlchemy` `joblib`
